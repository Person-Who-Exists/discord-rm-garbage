# Discord Garbage Remover
The name is self explanatory, this theme removes a lot of garbage from the discord ui
You can toggle whether things are hidden easily in your garbageRemover.theme.css file.

## Installing
Download the garbageRemover.theme.css file and place it in your discord mod's themes directory and then enable it in the gui.
Then simply change on to off or vice versa to toggle certain hidden objects.
